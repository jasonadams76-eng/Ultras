# The Ultras

A 3D open-world superhero game that runs in your browser. Choose **Silver Star** or **Thunder Bolt**, find Victor Cross at the ORACLE plaza, and take on the Corvetti family.

**Play:** https://jasonadams76-eng.github.io/Ultras/

## Controls
Press **H** in game for the full list. Esc returns to character select, K cycles costumes, M mutes, Shift+F toggles full screen. Keyboard + mouse or a standard controller.

## Run locally
Double-click `start.bat` (Windows) and open http://localhost:8000
